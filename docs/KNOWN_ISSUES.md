# Known issues and honest limits

## Things nobody has done yet (the biggest caveats)
1. **No human has played any shard.** Everything here was verified by automated tests, scripted bot play, headless screenshots that were inspected, and arithmetic. Feel, difficulty, pacing and "is it fun" are unknown. Every balance number (damage, prices, speeds, enemy health, day length, AI aggression) is a first draft.
2. **No human has listened to the audio** (see `AUDIO.md`). Loudness, loop seams and clipping were measured; musical quality and mix balance were not judged by ear. Sound was played only to SDL's dummy driver.
3. **Real controllers are untested.** Input logic is covered with synthetic SDL events and virtual devices (hot-plug, remap, pause on pad loss); no physical Xbox / PlayStation / Switch pad has touched it. Dead zones are the most likely thing to need a tweak.
4. **Developed and run on Windows 11 + Python 3.12.** The test suite also passes headless on Ubuntu in GitHub Actions, but no window was ever opened on Linux, and macOS was not tried. `pygame.SCALED` (experimental) has a fallback but multi-monitor and high-DPI behaviour is unchecked.
5. **Frame times are headless numbers** (dummy video driver, no vsync, no window presentation). They show the simulation and drawing are cheap on this machine (0.7-2.3 ms per frame per shard); they do not prove a smooth 60 fps on a slow GPU or integrated display.

## By shard

### Verdant
* Reputation is stored (and echoes can read it) but does not change prices or dialogue.
* Conversations are menu-based (greeting by hour, quest offers, flag-gated topics); no branching trees.
* Interiors are generated per *kind* (all inns share a layout) rather than authored per building.
* NPCs and enemies do not avoid each other; two can overlap in a doorway. NPC walking only runs near the player; elsewhere schedules snap.
* One wayshrine per world; no fast travel. Planks are bought rather than felled.
* The first time a 16x16-tile chunk is drawn costs up to ~38 ms (one-frame hitch); steady state is ~1.3 ms.
* Landmark JSON in `data/verdant.template/` is generated by `tools/gen_verdant_templates.py`; hand edits to the JSON are overwritten if the tool is re-run.
* Save version 1 has no migration path yet.
* Dungeon darkness is deliberately strong; the lantern radius is ~92 px (about 5.7 tiles).

### Concord
* House balance: bot campaigns complete as Ostrel, but the other houses were not balanced against a human; the large map was exercised least.

### Terrace
* Herbivores cluster and can graze the area around the player bare; breeding is capped but the distribution looks artificial. No irrigation, no wiring.

### Cinder / Slipstream / Masks / Umbra / Orrery
* Balance and handling untested by hands (see above). Slipstream has one championship; Masks has six fighters; Umbra has three nights; Orrery has no planet surfaces.

## Engineering notes
* `core/music.py` had an off-by-one in `room_ir` (an array one sample short) that made *every* track fail to render until the audio pipeline was first run; it is fixed (`CORE_CHANGES.md`).
* Thirteen sound recipes in three modes had been failing silently in game; fixed and now caught by `tools/gen_audio.py` (details in `AUDIO.md`).
